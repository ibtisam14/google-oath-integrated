# 🌐 Django Social OAuth Integration

This project demonstrates how to integrate **Google**, **GitHub**, and **Facebook** OAuth authentication in a Django backend.  
Users can log in or sign up using their social accounts and retrieve their profile information securely.

---

## 🚀 Features

- ✅ Google OAuth 2.0 login  
- ✅ GitHub OAuth login  
- ✅ Facebook OAuth login  
- ✅ Secure redirect-based authentication flow  
- ✅ Clean JSON responses (ready for frontend or Postman testing)  
- ✅ Environment-based configuration using Django settings  

---

## 🧩 Tech Stack

- **Backend Framework:** Django 3.2+  
- **HTTP Requests:** `requests` library  
- **Language:** Python 3.9+  
- **Auth Providers:** Google, GitHub, Facebook
